凸透鏡成像 2D・3D

不只看一支箭頭：把整個圖形放到凸透鏡前，每一個點各自成像，像會被拉長、壓扁、翻轉。2D 和 3D 用的是同一組圖形，3D 只是幫它加上厚度；在任一頁調整位置與大小，另一頁也跟著變。

拖動左邊的圖形，或用下面的滑桿改變它的位置與大小。實像畫成實心，虛像畫成斜線、虛線外框。黑點是選取圖形的標記點，彩色線是它的三條特殊光線。

這裡的立體物，就是 2D 頁的同一組圖形加上前後厚度：長方形 → 長方體、三角形 → 三角柱、圓形 → 圓柱、箭頭 → 箭頭板。彩色面朝向你，灰色面在背後。在畫面上拖動可旋轉視角；虛像半透明、虛線外框；細線是標記點通過透鏡中心的光線。

觀察重點

  1. 長方形的像為什麼變成梯形？比較長方形「靠近透鏡的邊」和「遠離透鏡的邊」的物距，看讀數中兩端的放大率。
  2. 只拉「寬」、不拉「高」：像的寬（沿主軸）怎麼變？讀數的「寬度放大率」為什麼剛好等於兩端放大率相乘？
  3. 把長方形整個移到 2F 外、F 與 2F 之間，像的寬度各變長還是變短？
  4. 把圓形慢慢拖過 F：圓形跨在焦點上時，像為什麼分成兩塊、而且延伸到畫面外？

觀察重點

  1. 按「正側面（＝2D）」：看到的和 2D 頁一樣嗎？（立體圖有透視，所以會有一點差別。）
  2. 按「從透鏡右邊看」：彩色面跑到哪一邊了？實像是上下顛倒、前後（左右）顛倒，還是兩個都有？
  3. 拉「厚度」：像的前後厚度跟著「高」一起放大；沿主軸的寬卻是兩端放大率相乘。為什麼同一個物體，三個方向放大的倍數不一樣？
  4. 把圖形移到 F 內，虛像在哪一邊？是正立還是倒立？
依幾何光學的理想薄透鏡（近軸）計算：物體上每一點各自用 1/p ＋ 1/q ＝ 1/f 成像，所以透鏡畫多大都不影響結果。實際透鏡有像差，靠近透鏡邊緣或角度很大的光線會偏離這個結果。
